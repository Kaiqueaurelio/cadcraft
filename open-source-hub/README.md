# Decode Open Source Hub

Central visual oficial mantida pela Decode Analytics para explorar e baixar a suíte de ferramentas criativas e produtivas de código aberto.

## Estrutura

- `index.html`: site estático em HTML, CSS e JavaScript puros, sem dependência de build externo ou frameworks pesados.
- Catálogo oficial: 14 ferramentas Decode Analytics (Decode Photo, Decode Light, Decode Film, Decode Design, Decode Vector, Decode PDF, Decode Effects, Decode Writer, Decode Slides, Decode Sheets, Decode Draft, Decode Audio, Decode UI e Decode CAD), cada uma com links para o respectivo repositório e página de releases oficiais.
- Consulta as releases oficiais públicas no GitHub da Decode Analytics para exibir versões e direcionar os pacotes oficiais.

## Publicação na Vercel

Configure o projeto para usar a pasta `open-source-hub` como Root Directory. Como é um site estático, não é necessário comando de build nem dependências de instalação.
