# Publicação de versões do CADCraft

O procedimento oficial é o [manual de publicação do craftrules](https://github.com/storytold/craftrules/blob/main/release/playbook.md). Este arquivo registra apenas os detalhes específicos do CADCraft.

- **Versão:** `[workspace.package] version` no `Cargo.toml` da raiz é a fonte única. `cargo xtask version` exibe a versão; `cargo xtask version set X.Y.Z[-pre]` altera o valor. A versão aparece na janela Sobre, em `cadcraft --version` e `cadcraft-cli --version`. Builds de publicação também incorporam o commit por meio de `CADCRAFT_BUILD_SHA`.
- **Criar uma publicação:** atualize a versão em `main` e envie `main` para `release` com `git push origin main:release`. Cada envio à branch `release` executa `.github/workflows/release.yml` e cria ou atualiza o rascunho da versão `CADCraft v<versão>` no GitHub. Uma execução `workflow_dispatch` com `version: X.Y.Z-rc.N` cria um build de teste. A execução manual em outra branch é apenas uma simulação: os trabalhos sem assinatura compilam, o ambiente `release` bloqueia as tarefas de assinatura (macOS e Windows) e nenhuma versão é criada.
- **Artefatos:** DMG universal para macOS (assinado com Developer ID, notarizado e com ticket anexado) e ZIP da CLI; MSI e ZIP portátil para Windows x64, x86 e arm64; AppImage para Linux x86_64 e aarch64, arquivo `.AppImage.zsync` para atualizações incrementais, pacote Flatpak, `.deb`, `.rpm`, `.tar.gz` e manifesto Flathub para compilação a partir do código-fonte; pacote `.tar.gz` para Linux riscv64; pacote `.tar.gz` para FreeBSD x86_64; ZIP web com WebAssembly e `index.html` (consulte o [guia de hospedagem web](../packaging/web/README.md)); e `SHA256SUMS.txt`.
- **Segredos de assinatura:** os doze segredos ficam no ambiente `release`, implantável somente a partir da branch `release`, na qual apenas administradores da organização e responsáveis por publicação podem enviar alterações. Todos são opcionais; se algum estiver ausente, o artefato correspondente é produzido sem assinatura e com um aviso.
- **Instalador do Windows:** `packaging/windows/cadcraft.wxs` usa WiX v5 e `WixToolset.UI.wixext`. O assistente tem uma página de atalhos: o atalho no menu Iniciar é sempre criado; o atalho na área de trabalho é opcional. Em instalações silenciosas, `DESKTOPSHORTCUT=1` o cria e `DESKTOPSHORTCUT=0` o remove durante uma atualização; sem essa variável, a atualização mantém a escolha anterior.
- **Tipos de arquivo:** `.dxf` e `.dwg` são registrados como tipos de documento no macOS, opções de “Abrir com” no Windows e tipos MIME no Linux.
- **Teste local de empacotamento:** `packaging/macos/package.sh` cria um DMG com assinatura ad hoc; use também `packaging/linux/package.sh` e `packaging/web/package.sh` para os respectivos formatos.
